# Data-Driven Testing with Playwright and Python

This practice project demonstrates how data-driven testing works with Playwright and Python, using CSV data to test multiple login scenarios.

Tools and Technologies

Editor: Visual Studio Code

Browser automation: Playwright

Test framework: pytest

Language: Python

Test data: CSV

Data reading: pandas

This project uses the Sauce Demo login page to practise testing with valid, invalid, and empty credentials.

The same test function runs once for each CSV row and compares the actual outcome with the expected result.
